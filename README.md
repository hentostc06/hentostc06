## Tentang saya

Saya bekerja di bidang **IT support, jaringan, dan infrastruktur server**. Fokus saya mencakup troubleshooting konektivitas, administrasi server Linux, serta backup, pemulihan data, dan monitoring. Saya juga membangun aplikasi web untuk kebutuhan operasional dan pendidikan.

[Portofolio](https://github.com/hentostc06/henri-portofolio) · [Semua repositori](https://github.com/hentostc06?tab=repositories)

## Proyek pilihan

- **[HenryTools](https://github.com/hentostc06/henrytools)**  
  Perkakas PDF untuk menggabungkan, memisahkan, dan mengedit dokumen langsung di browser. Dibangun dengan Next.js, TypeScript, dan pdf-lib.
- **[Absensi Digital](https://github.com/hentostc06/Absensi-Digital-SMA-Muhammadiyah-2-Kota-Tangerang)**  
  Sistem absensi siswa dengan QR dinamis, pemantauan kehadiran, dan ekspor laporan. Dibangun dengan Laravel dan MySQL.
- **[Course LMS](https://github.com/hentostc06/course-lms)**  
  Marketplace kursus dengan katalog, pengelolaan materi oleh instruktur, moderasi, dan pelacakan progres belajar. Dibangun dengan Laravel, Vue, Inertia, dan Filament.

## Teknologi yang saya gunakan

- **Jaringan** · LAN, VLAN, MikroTik, Ruijie, dan WireGuard
- **Server** · Linux, Docker, Nginx, Samba, Nextcloud, dan rsync
- **Pengembangan web** · Laravel, Vue, Next.js, TypeScript, PostgreSQL, dan MySQL
